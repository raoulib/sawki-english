🔒 Politique de Confidentialité

Dernière mise à jour : Septembre 2026

Sawki English est une application d'apprentissage de l'anglais américain éditée par Sawki Group. Nous prenons la protection de vos données très au sérieux.

1. Données collectées

Nous collectons les données suivantes, uniquement pour le fonctionnement de l'application :

  • Prénom / Pseudo — pour personnaliser votre expérience d'apprentissage
  • Adresse email (optionnel) — pour la sauvegarde cloud de votre progression
  • Données d'apprentissage — niveau actuel, leçons complétées, score XP, erreurs fréquentes
  • Enregistrements vocaux temporaires — uniquement pour l'évaluation de prononciation en temps réel, non stockés

2. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Sauvegarder et synchroniser votre progression d'apprentissage
  • Personnaliser les exercices et le tuteur IA
  • Générer vos certificats de compétence linguistique
  • Améliorer la qualité pédagogique de l'application

3. Microphone

L'application utilise le microphone de votre appareil uniquement pour :

  • La reconnaissance vocale lors des exercices de prononciation
  • Les conversations orales avec le tuteur IA Sarah

Les enregistrements audio sont traités en temps réel et ne sont jamais stockés ni transmis à des tiers.

4. Stockage et sécurité

  • Les données locales sont stockées de manière chiffrée sur votre appareil via Hive
  • Les sauvegardes cloud transitent via Supabase avec chiffrement TLS
  • La clé de récupération Sawki est chiffrée avant export

5. Services tiers

Sawki English utilise les services tiers suivants :

  • Google AdMob — affichage de publicités (soumis à la politique Google)
  • Google AI (Gemini) — tuteur IA conversationnel
  • Supabase — stockage cloud sécurisé

6. Partage des données

Nous ne vendons, n'échangeons ni ne transférons vos données personnelles à des tiers, sauf obligation légale.

7. Droits de l'utilisateur (RGPD)

Conformément au Règlement Général sur la Protection des Données, vous disposez des droits suivants :

  • Droit d'accès — consulter vos données stockées
  • Droit de rectification — modifier vos informations
  • Droit à l'effacement — supprimer votre compte et toutes les données associées
  • Droit à la portabilité — exporter vos données via la Clé Sawki

8. Enfants

Sawki English peut être utilisé par des enfants de plus de 13 ans. Pour les utilisateurs de moins de 13 ans, le consentement parental est requis.

9. Modifications

Nous nous réservons le droit de modifier cette politique. Toute modification sera notifiée via l'application.
